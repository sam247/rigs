4. **Harpenden location (P3) — deferred**

   `/services/emergency-electrician` ~749–1009 impressions, avg pos ~45–47, near-zero CTR. Mostly location long-tails. Title already location-aware. **Left unchanged** pending ranking improvement via location service pages / links.
